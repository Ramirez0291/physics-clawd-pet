# Physics Clawd Pet v2.6.0

## A calmer tuning panel

- Everyday controls come first: size, walking speed, input avoidance, throw strength and bounciness.
- Other parameters are organized into Physics, Behavior and Appearance tabs, with one advanced group expanded at a time. Search and “changed only” work across all categories.
- A single Action menu opens a categorized popup for daily activities, window play, reminders, test throws and character-specific clips. Choosing an action closes the popup so you can watch the pet.
- Detailed telemetry, JSON tools, reset-to-default and pinning are tucked away. Live tuning, saving and character switching remain available.

## 更清爽的调教面板

- 首页只保留大小、走路速度、输入框避让、甩出力度和地面弹性，先调最常用的几项。
- 其他参数按「物理 / 行为 / 外观」分类，高级参数一次展开一组；搜索和「只看改过的」覆盖所有分类。
- 动作统一收进分类弹框：日常互动、窗口玩耍、提醒、测试投掷，以及角色专属播片。选中即执行，菜单自动收起。
- 详细状态、JSON 工具、恢复默认和面板置顶按需展开；实时调节、保存和切换形象继续可用。
