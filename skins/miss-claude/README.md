# miss.claude

根据用户提供的《橘发菊花纹桌宠像素动作参考图》制作的同人皮肤。
`character.png` 是使用内置 imagegen、以参考图左侧立绘为基础生成的透明角色图，
保留橘色长卷发、白色环状呆毛、菊花、黑缎带与流苏、黑色菊花纹罩裙和米白橘边裙装。
白色环状造型是呆毛。此图经过模型处理，并非原文件的逐像素裁切。

在桌宠的 **形象 → 拟人角色 → miss.claude** 中选择，也可以在调教面板的形象下拉框中切换。

## 原画骨架

使用 `render: "sprite"`，以透明 PNG 裁片代替低分辨率 ASCII 重绘。
身体保留头发、脸型和衣服细节；袖子绕肩关节转动，腿跟随步态，眼睛眨眼并轻微跟随光标，
呆毛绕发根摆动。`category: "humanoid"` 采用独立的人物姿态适配，Clawd、Dots 等继续使用宠物动作。

## 拟人动作

`motion-atlas.png` 由内置 imagegen 依据已确认角色图与原始动作参考图生成，为 4×4 透明动作图集。
运行时统一对齐主体中心和脚底，保持帧间尺度，避免整个人在换帧时横跳。

| 行为 | 人物适配 |
| --- | --- |
| 行走 | 四帧侧向步态，按接触面的本地朝向镜像；右墙、天花板的旋转也计入方向判断 |
| 摸摸 | 两帧恋爱反应：脸红、双手合在胸前、睁眼/闭眼微笑与爱心 |
| 读书 | 坐着捧书，两帧阅读/翻页 |
| 写字 | 坐着写笔记，两帧笔尖和手部变化 |
| 思考 | 托腮思考，两帧视线/气泡变化 |
| 被拎起/甩飞 | 惊讶、收手、屈膝的专门姿势，保留抓取点和真实自转 |
| 翻滚 | 抱膝姿势绕自身中心旋转，并按当前轮廓贴合地面 |
| 普通/英雄落地 | 屈膝、单手撑地缓冲 |
| 脸着地 | 趴倒姿势，限制脸部的压扁程度 |
| 贴边 | 读取 `motions.png` 参考图中的对应动作格，渲染时去掉纸色和边缘孤点 |
| 伸懒腰 | `stretch.png` 独立四帧：起手、抬手、伸展、收手，保持当前人物造型，只播一遍 |
| 电脑、炒股、吃TOKEN及提醒动作 | 保留部件骨架和道具，使用人物形变限制；手臂继续绕肩转动 |

读书、写字和思考会加入随机活动，也可从调教面板直接触发。
坐姿活动只在地面/窗口顶上开始，能被抓取、摸摸和提醒打断；换成不会该动作的皮肤时退出活动。
物理引擎的速度、碰撞、投掷、自转、粒子与轨迹继续共用；拟人贴图单独限制过强的拉伸和压缩。

原画裁剪坐标、蒙版和关节在 [`scripts/skins/miss-claude.mjs`](../../scripts/skins/miss-claude.mjs)。
修改后运行 `npm run skin:miss-claude` 生成 `skin.json`。一格对应 40 个源图像素。

## 图像处理提示

内置 imagegen，透明背景；输入为用户提供的参考图。提示要求提取左侧单个站立角色，
移除文字、表格和其他小人，保留脸型、头身比例、卷发、瞳色、菊花、黑缎带、白色环状呆毛和裙装细节；
不重新设计、不添加帽子。角色图保存于本目录，运行时不依赖图片生成服务。

动作图集的完整生成提示见 [`motion-atlas-prompt.txt`](motion-atlas-prompt.txt)。
伸懒腰同样由内置 imagegen 依据 `character.png` 与动作图集生成，提示见 [`stretch-prompt.txt`](stretch-prompt.txt)。

方向说明：物理引擎的 `dir` 沿世界 x/y 递增；身体在右墙和天花板旋转后，本地 +X 与该增量相反。
方向镜像在 `src/render/motions.ts` 统一换算，切换方向也会使渲染缓存失效。

## 窗口游乐场

`windowPlay: true` 开启基于真实窗口状态的玩法，独立素材位于 `window-play.png`（4×3 图集）。

| 动作 | 触发方式 |
| --- | --- |
| 坐标题栏晃腿 | 站在足够宽的窗口上时随机触发，也可点「坐标题栏」；以臀部为接触点，双腿自然垂到标题栏下面 |
| 边缘探头 | 先真实走到最近的窗口边缘，再蹲下探头；窗口移动时先暂停脚步扶稳 |
| 张手平衡 | 脚下窗口正在被拖动，或身体产生明显惯性倾斜时触发 |
| 急停踉跄 | 轻微急停后先惊讶、再恢复平衡；猛烈急停继续执行原来的惯性甩飞 |
| 跳窗蓄力 | 跳到其他窗口前屈膝约 0.34 秒，起跳前重新检查窗口是否还存在、是否仍可到达 |
| 腾空跳跃 | 由真实弹道带到上方、平级或稍低的窗口；计入引擎的顶点减速和空气阻力 |
| 落窗得意 | 真正落到窗口顶上后短暂微笑、握拳庆祝 |
| 窗口消失惊慌 | 脚下窗口关闭、最小化或被遮挡，立即失去支撑并惊慌下落 |

「坐标题栏」「边缘探头」「跳窗」在调教面板可直接触发；条件不满足时按钮置灰。
坐/探头需要先把角色放到窗口顶上，跳窗需要附近有可到达的窗口。
被抓起、换皮肤或目标窗口消失都会取消尚未执行的跳跃。
窗口动作图集由内置 imagegen 依据已确认角色图集制作，提示见 [`window-play-prompt.txt`](window-play-prompt.txt)。
