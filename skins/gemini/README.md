# Gemini

从托盘菜单的「形象 → 拟人角色」切换。正面保留粉金异色瞳、四角星发饰、蓝紫长卷发和渐变猫尾。待机时会眨眼、侧目，摸头时先脸红再抱臂。

调教面板可触发读书翻页、写字、敲电脑、思考、炒股、吃 TOKEN 和伸懒腰。放到窗口标题栏上，她可以晃腿、探头、在移动时张袖站稳，还会在跳窗落地时比 V。

四张透明图集由 ImageGen 根据角色设定图生成。每帧按鞋底或臀部标定接触点，左右行走各有四帧。裁片和动作顺序由 [生成脚本](../../scripts/skins/gemini.mjs) 维护，修改后运行 `node scripts/skins/gemini.mjs`。完整提示词见 [imagegen-prompts.txt](imagegen-prompts.txt)。
