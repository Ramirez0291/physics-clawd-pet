# 蓝色大肥鱼

在托盘的形象菜单里展开「拟人角色」，选择「蓝色大肥鱼」。她和原来的 DeepSeek 娘各占一个位置。

站姿取自设定图的「普通」帧，伸懒腰也从这一帧起手、收手。走路、读书和窗口互动使用同一张图的小帧。每帧按头部定标，以相同的像素大小显示，再把脚底或臀部对准接触线。

把她放上窗口标题栏，可以在调教面板里让她晃腿、探头，或者跳到附近够得着的窗口。拖动窗口时她会扶稳，急停会踉跄或被甩飞，脚下的窗口关掉时她会掉下来。

`reference.png` 是原设定图。裁片坐标、呆毛环里的纸色区域、采样间距和接触点在 [生成脚本](../../scripts/skins/blue-whale.mjs) 中标注。修改后运行 `node scripts/skins/blue-whale.mjs` 更新 `skin.json`。
