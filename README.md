# Physics Clawd Pet

一个桌宠。可以把它拎起来甩出去：它会像被干飞出的DIO一样翻滚落地，像超级英雄一样砸出烟尘，或者像蜘蛛侠一样贴在屏幕边上。

技术栈：Tauri 2（Rust 负责原生窗口）+ TypeScript（物理、渲染、调试面板）。

## 现在能做什么

**和桌面上的窗口互动**

- 站在窗口上：从上面落下会站住（单向平台，从下面能穿过去）；会自己跳上附近的窗口，走到窗口边缘会跳下去，在窗口顶上翻滚会滚出边缘
- 拖动它脚下的窗口：平稳拖动会被带着走，快速拖动后急停会顺着惯性被甩飞；往上提再急停会被抛起来；猛地一拽会把窗口从它脚下"抽走"
- 脚下的窗口被关掉、最小化或者被别的窗口挡住，它会掉下去
- 全屏免打扰：前台有全屏程序（游戏、全屏视频、演示）时自动隐藏，退出全屏后从天上掉回来；托盘菜单也可以手动隐藏
- 换分辨率、挪任务栏后覆盖层自动跟着调整
- 光标、悬停、窗口枚举都在 Rust 原生线程里做，只在有变化时通知前端

**物理**

- 透明置顶覆盖层，只有宠物本身能被点到，其余区域点击穿透；点宠物不会抢走当前窗口的焦点
- 拎起来时像钟摆一样晃；抓腿会倒挂，甩太猛会晕
- 甩出去后按冲击速度分级落地：普通落地 / 弹跳 / 翻滚 / 超级英雄落地 / 脸着地
- 高速撞到左右屏幕边或天花板会贴住，然后沿边框爬行、蹬墙后空翻跳下
- 自己会在任务栏上走来走去、爬墙、倒挂天花板，眼睛跟着鼠标
- 手感相关的打击感细节：顿帧、果冻形变、速度拉伸、残影、烟尘和冲击线
- 像素风渲染：先在低分辨率网格里旋转、再最近邻放大，转起来像素块依然整齐
- 调试面板：60 多个手感参数实时调整，带慢动作、暂停/单步、可重复的测试投掷和"重放上次投掷"

## 运行

需要：Node.js 20+、Rust（MSVC 工具链）、Visual Studio C++ 生成工具、WebView2（Win11 自带）。

```bash
npm install
npm run tauri dev
```

开发模式会同时打开调试面板。托盘图标左键打开调试面板，右键有"把 Clawd 叫回来"和"退出"。

只想调物理、不想编译 Rust 的话，可以直接在浏览器里预览：

```bash
npm run dev
```

然后打开 http://localhost:1420 ，按 `D` 打开调试面板（两个页面通过 BroadcastChannel 通信）。

打包安装程序：

```bash
npm run tauri build
```

产物在 `src-tauri/target/release/bundle/nsis/`。

## 调教模式

1. 在调教面板里拖滑块，改动立即生效。
2. 保存的调教参数在 `%APPDATA%\com.physicsclawdpet.desktop\tuning.json`，下次启动自动加载。
5. 想把调好的值变成默认值：点"复制 JSON"，贴回 `src/engine/params.ts` 的 `DEFAULT_TUNING`。

## 目录结构

```
src/
  engine/     纯逻辑，不碰 DOM，可以单测
    params.ts     所有手感参数和调试面板的控件定义
    pet.ts        物理 + 状态机（飞行/落地分级/翻滚/贴墙/爬行/抓取钟摆）
    pose.ts       程序化动作：按部件角色给每个部件算偏移
    particles.ts  烟尘、碎屑、冲击线
    throw.ts      松手速度估计（最小二乘拟合最近一段鼠标轨迹）
  render/     像素风栅格化和特效绘制
  overlay/    覆盖层入口：主循环、鼠标、和调试面板的通信
  debug/      调试面板
  platform/   Tauri / 浏览器两套实现（事件总线、点击穿透、光标、存参数）
  skin/       皮肤格式定义和加载
skins/clawd/  Clawd 皮肤（同人，见该目录的 README）
src-tauri/    Rust：透明覆盖窗口、托盘、参数读写
  src/desktop.rs  Win32 只读查询：光标、可见窗口、可站顶边（含遮挡计算）、全屏检测
  src/watcher.rs  桌面观察线程：点击穿透、窗口平台推送、脚下窗口高频追踪、免打扰
tests/        引擎单测（npm test）
```

## 皮肤格式

皮肤JSON：网格大小、调色板、一组矩形部件。每个部件标一个角色：`body` / `eye` / `arm` / `leg`。
引擎只认这四种角色，所有动作都按角色程序化生成，添加新皮肤可以不用画任何动画帧。参考 `skins/clawd/skin.json`。
